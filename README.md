# BioChem Academy — репозиторий учебного проекта по биологии и химии

Открытый, модульный репозиторий для подготовки и проведения занятий по биологии и химии (репетиторство / тьюторинг / мини-курсы). Структура рассчитана на то, чтобы:

- легко добавлять новые темы и уроки, не ломая структуру;
- переиспользовать проверенные открытые материалы (OER), а не писать всё с нуля;
- держать методические материалы (планы, шаблоны, критерии оценивания) отдельно от контента уроков;
- при желании — открыть репозиторий как публичный OER-проект.

## Структура репозитория

```
biochem-academy/
├── README.md                  # этот файл
├── SYLLABUS.md                 # цели курса, компетенции, итоговая структура
├── CONTRIBUTING.md             # как добавлять/менять материалы
├── LICENSE                     # лицензия на ваш собственный контент
├── curriculum/
│   ├── biology/                # модули по биологии
│   └── chemistry/              # модули по химии
├── templates/
│   ├── lesson-template.md      # шаблон урока
│   └── quiz-template.md        # шаблон теста/квиза
├── docs/
│   └── resources.md            # проверенные источники и OER-платформы
├── schedule/
│   └── 12-week-plan.md         # пример учебного плана на 12 недель
└── assessments/                 # проверочные работы, критерии оценивания
```

## Как пользоваться

1. Каждая тема в `curriculum/biology/` и `curriculum/chemistry/` — отдельная папка вида `NN-название-темы/`, внутри — `lesson.md`, сделанный по `templates/lesson-template.md`.
2. Перед тем как писать урок с нуля, загляните в `docs/resources.md` — там проверенные ссылки на открытые учебники, симуляции и видео, которые можно адаптировать под конкретного ученика.
3. `SYLLABUS.md` — это "карта" курса: какие модули есть, в каком порядке идут, какие компетенции закрывают.
4. `schedule/12-week-plan.md` — готовый пример недельного плана, который можно копировать под конкретного ученика/группу и менять даты.

## Философия

Репозиторий построен по циклу **find → adapt → use → refine → share**: не пишем материалы в вакууме, а берём лучшие открытые источники (LibreTexts, OpenStax, CK-12, PhET, Khan Academy), адаптируем под уровень и язык ученика, тестируем на занятии, дорабатываем и сохраняем финальную версию в репозитории — чтобы в следующий раз не начинать с нуля.
